# Подарок для Batoni009

Полноценный веб-проект: мини-игра на Canvas, разблокировка персонального AI-чата и backend-прокси к Pollinations.

## Запуск

```bash
npm install
npm run dev
```

Frontend откроется на `http://localhost:5173`, backend работает на `http://localhost:3001`.

## Production / Render

```bash
npm run build
npm start
```

Render:
- Build command: `npm run build`
- Start command: `npm start`
